## Mô tả dự án
Hệ thống quản lý bán hàng bao gồm các chức năng chính: Quản lý danh mục, sản phẩm, khách hàng và đơn hàng.

## Hướng dẫn cài đặt cơ sở dữ liệu
1. Mở SQL Server Management Studio (SSMS).
2. Tạo một Database mới.
3. Mở file `Database_Setup_OnlineSales.sql` và nhấn **Execute (F5)**.
4. Hệ thống sẽ tự động tạo bảng và chèn dữ liệu mẫu.
